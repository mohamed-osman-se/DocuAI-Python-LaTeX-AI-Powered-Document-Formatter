# DocuAI (Python + LaTeX) – AI-Powered Document Formatter

This Python API will allow you to transform plain text into professionally formatted PDFs using AI and LaTeX. The project is **currently in development** and coming soon! 🚀

## How It Will Work

1. **Input Your Text**  
   Provide your raw text content that you want to format.

2. **Choose a Style**  
   Select from predefined formatting styles (e.g., Formal, Minimalist, Creative) or let the AI suggest the best layout.

3. **AI-Powered Formatting**  
   The AI will analyze your text and generate LaTeX code tailored to your chosen style, ensuring professional typography and layout.

4. **PDF Generation**  
   The LaTeX code will be compiled into a high-quality PDF, ready for download or sharing.
